Objectives

The main objectives of this project are to:

1. Calculate basic descriptive statistics such as mean, median, count,
minimum, and maximum.
2. Identify trends outliers.
3. Summarize key observations from the dataset.

Revenue Trend

it is consistent with the recorded quantity and unit price rather than
appearing to be a data-entry error.

Data Quality

The dataset was cleaned by:

• Handling missing values
• Replacing missing CouponCode values with “No Coupon”
• Checking for duplicate records
• Standardizing date formats
• Standardizing numeric fields
• Formatting monetary values to two decimal places

A total of 309 missing CouponCode values were handled, and no
exact duplicate rows were identified.
